# 2023_GMTK_GameJam

This is a game submitted to the 2023 GMTK GameJam. The theme was "Roles Reversed". We took this in the direction of a puzzle game about fixing a game to submit to a Game Jam.

Download page for the game on Itch.io (no Mac support only .exe build): https://ricric132.itch.io/placeholder-title
